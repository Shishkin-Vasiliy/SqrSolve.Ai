README

Программа SqrSolve.Ai создана для решения квадратного уравнения. Она включает в себя множество различных опций, режимов работы, систему UNIT-тестирования и графическую отрисовку. Написана на языке Си под систему WSL Ubuntu, успешно работает на любом дистрибутиве Linux.

Возможности:

1) Пользователь вводит коэффициенты квадратного уравнения через пробел, программа решает уравнение и выводит в консоль полную информацию об уравнении: введенные коэффициенты, посчитанный дискриминант и количество корней, а также вычисленные корни.
Программа справляется с случаями квадратного уравнения с вещественными корнями, со случаем линейного уравнения, квадратного уравнения с комплексными корнями и уравнения с бесконечным количество корней.
В случае некорректного введения коэффициентов, программа выводит ошибку:
ERROR: некорректное квадратное уравнение.

2) Можно решать несколько уравнений подряд: после каждого решения пользователь может ввести новые коэффициенты и получить новое решение.

3) Если программа запущена в специальном режиме (см. Режимы работы), то помимо вычисленных корней на экран выведется график уравнения.

4) В программе предусмотрена система UNIT-тестирования - его можно запустить самостоятельно с помощью специального флага (см. Режимы работы).

5) После каждого решенного уравнения программа сообщает о количестве оставшихся на счету пользователя токенов.

6) В конце работы программы на экран выводится история решенных уравнений (по умолчанию последние 5).

Установка и запуск программы:

1) Скачайте исходные файлы программы на свой компьютер.

2) Скомпилируйте программу с помощью команды ./scr.sh. Здесь scr.sh - скрипт с нужными флагами компиляции.

3) Для запуска программы используйте команду ./sqr.out.

Режимы работы:

1) Пользовательский режим (флаг -u) - решение квадратного уравнения.
Это режим по умолчанию, поэтому, если необходимо запустить программу именно в этом режиме, то можно не писать никаких флагов.

2) Пользовательский режим с графикой (флаг -g) - решение квадратного уравнения и отрисовка графиков уравнений. Можно запускать отдельно, а также совместно с флагом -u или с одновременно включенными флагами -u и -t (флаг тестирования, о нем ниже).

3) Режим тестирования (флаг -t) - запуск UNIT-тестирования. Можно использовать отдельно, а также совместно с флагом -u или с одновременно включенными флагами -u и -g.

Система тестирования:

1) В файле Tests.txt находятся тесты, на которых программа будет протестирована (в нем содержатся различные частные случаи квадратного уравнения, а также один базовый случай)

2) В файле RefTests.txt находятся эти же тесты в решенном виде (эталонные тесты).

3) Система тестирование читает оба файла, решает уравнения, содержащиеся в Tests.txt и сравнивает результат с эталонным.

4) При обнаружении ошибки программа выводит сообщение с ее описанием и кодом.
